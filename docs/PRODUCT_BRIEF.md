# Product Brief — IntelliTrip

## One-liner
A sovereign Android app that renders live Metro Transit vehicles and live weather radar on one map, scoped from "just my trip" to the whole system.

## Target user
Twin Cities riders who want a calm, clean default map plus a dev-grade advanced mode — not yet another cluttered transit app.

## Pillars
1. **One app** — no separate lite/pro apps; advanced features hidden behind a setting.
2. **Sovereign engine** — Atlas engine is modular and portable so Recovery for All (and future apps) can embed the routing/transit core.
3. **Scope dial** — anything from a single trip to the full system view.
4. **Plan-first** — no code without this doc set.

## Non-goals (v1)
- iOS, web, desktop
- Fare payment / account features
- Turn-by-turn navigation (routing is phase 4, read-only planning)

## Success criteria for v1
- Live bus/rail positions within ~15s on the map
- Radar overlay within one tap
- Scope dial changes rendered layer density/follow mode
- Cold start < 3s to interactive map
